# 초기 CPU 실행 검증 — 2026-10-12

Windows / Python 3.12.14에서 저장소 기본 설정으로 실제 EIA 자료를 처리하고 `python -m ripple.train --device CPU`를 실행한 기록입니다. GPU 성능 측정 결과가 아닙니다. GPU PC의 설치·연산 성공 여부는 별도로 확인해야 합니다.

- 공식 EIA 페이지에서 연도별 다운로드 링크 확인 및 기존 원본 ZIP 해시 검사 성공.
- 원본 ZIP 재전처리: 원전 부지 냉각계통 3,372행 → 품질·범위 조건 통과 1,671행 / 27개 발전소.
- 학습 648행, 검증 320행, 시간 평가 321행, 미관측 발전소 평가 94행, 미사용 288행.
- Random Forest 500개 트리, Gradient Boosting 500회, CatBoost 최대 1,500회와 검증 조기 종료.
- 5종 모델 저장 성공. 선택 모델을 다시 불러온 실제 입력 5행 예측 성공.
- 새 가상환경에서 고정 버전 설치, 의존성 검사(`pip check`), 환경 검사 및 자동 검사 재실행 성공.
- 단위 변환, 분할, 목표값 유출 방지, 모든 모델의 저장·재로딩·예측 일치, 미학습 범주, 데이터 해시 변경 거부 등을 포함한 자동 검사 7개 통과.
